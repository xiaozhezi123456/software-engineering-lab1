# Sprint 计划与回顾

本项目按实验进程划分为 3 个 Sprint，每个 Sprint 以一次可演示的版本交付物结束。

## Sprint 1（迭代一）

- 目标：搭建仓库、协作规范与 CI，完成成绩录入与持久化；
- 包含 Issue：#1、#2；
- 验收标准：单元测试通过、GitHub Actions CI 绿色、代码合入 develop；
- 交付版本：v0.1.0 基线。
- 回顾：PR 合入流程顺畅；CI 在 PR 中自动运行，评审时能看到检查结果。

## Sprint 2（迭代二）

- 目标：成绩统计与排名，按评审意见修复边界缺陷，补充版本记录并解决冲突；
- 包含 Issue：#3、#4、#5；
- 验收标准：统计测试通过，空成绩列表不抛异常，CHANGELOG 冲突在 PR 中解决。
- 回顾：PR 评审发现除零缺陷（Issue #4），返工后复评通过；两人并行修改 CHANGELOG
  在 GitHub 上体现为 PR 不可自动合并，本地解决冲突后 PR 恢复可合并。

## Sprint 3（迭代三）

- 目标：命令行入口与成绩单报表，完成 v1.0.0 发布；
- 包含 Issue：#6、#7；
- 验收标准：CLI 正常输出报表，发布 PR 通过 CI 并合入 main，GitHub Release 创建成功。
- 回顾：全部 7 个 Issue 关闭，发布 PR 在 CI 通过后合入受保护的 main 并创建 v1.0.0 标签与 Release。
